# AITC 离线经验表训练工具 - 新手操作手册

本手册专门为**零基础运维人员**编写。只需按照本指南“**放文件 -> 敲命令 -> 看结果**”三步走，即可生成或更新路口通行能力离线经验底表。

> **提示**：核心算法引擎（`offline_trainer/` 文件夹）已封装加密，日常使用**无需打开或修改**。

---

## 一、工具包目录认识（文件放哪儿）

```text
tools/                           <--- 工作根目录
│
├── configs/                     <--- 【放配置文件】
│   └── cross_info.json          <--- 每次有新路口，把最新的 cross_info.json 复制到这里替换
│
├── logs_data/                   <--- 【放历史日志数据】
│   ├── flow/                    <--- 流量数据放这里（过车记录）
│   ├── extend/                  <--- 信控数据放这里（绿灯放行记录）
│   └── offline_training/        <--- 训练分析产物自动生成在此
│
├── experience_pool/             <--- 【经验底表存放处】
│   └── offline_experience.json  <--- 核心产物：训练结果会自动增量追加写入该文件
│
├── offline_train.py             <--- 训练启动脚本（主程序，直接敲命令运行）
└── offline_trainer/             <--- 核心加密算法库（已封装加密，请勿修改）
```

---

## 二、第一步：准备工作（放文件）

### 1. 复制路口配置
- 每次有新路口需要训练时，**直接将最新的 `cross_info.json` 复制到 `tools/configs/` 文件夹下替换覆盖**即可，无需手动修改文件内容。

### 2. 放置历史日志数据
将训练所需的两类数据文件放到对应目录下，文件命名格式必须为 **`年-月-日_类型.txt`**：

- **流量数据**：放在 `tools/logs_data/flow/`
  - 示例：`2026-07-01_flow.txt`、`2026-07-02_flow.txt` ...
- **信控数据**：放在 `tools/logs_data/extend/`
  - 示例：`2026-07-01_extend.txt`、`2026-07-02_extend.txt` ...

---

## 三、第二步：开始运行（终端敲命令）

### 1. 进入 tools 目录
```bash
cd /您的实际路径/tools
```

### 2. 快速体检（Dry Run 预检，只需 1 秒）
为了防止路口未配置或数据文件缺失，正式训练前先运行体检命令：
```bash
python offline_train.py --roads 路口ID --days 14 --dry-run
```
终端显示 `状态: dry_run_success` 即代表配置与日志齐全，可放心训练。

### 3. 正式训练（默认自动写入经验底表）
训练系统**默认已开启自动合并**，无需额外添加 `--merge` 参数：
```bash
python offline_train.py --roads 路口ID --days 14
```

#### 常见场景命令速查：

| 训练场景 | 复制粘贴执行的命令 | 说明 |
|---|---|---|
| **训练单个路口** | `python offline_train.py --roads 1300069 --days 14` | 自动计算并追加写入经验底表 |
| **训练多个路口** | `python offline_train.py --roads 1300069,1300068 --days 14` | 多个路口用逗号隔开批量训练 |
| **指定固定日期区间** | `python offline_train.py --roads 1300069 --dates 2026-07-01:2026-07-14` | 使用指定日期范围的日志 |
| **仅分析不改底表** | `python offline_train.py --roads 1300069 --days 14 --no-merge` | 仅生成单次分析报告，不更新底表 |

---

## 四、关于 `--days 14` 的取数时间规则

- **时间基准**：`--days 14` 读取的是**当前计算机操作系统的本地系统时间（北京时间）**。
- **倒推规则**：默认从计算机时间的**昨天**往前倒推连续 14 天（例如今天是 11月8日，昨天是 11月7日，14 天即 10月25日 ~ 11月7日）。
- **历史数据场景**：如果您手头的日志数据不是最近 14 天（比如是之前某个时间段的测试数据），请改用 `--dates 起始日期:结束日期` 参数，例如：
  ```bash
  python offline_train.py --roads 1300069 --dates 2026-07-01:2026-07-14
  ```
  这样系统就会严格使用这 14 天的历史文件，不受电脑当前时间的影响。

## 五、第三步：查看成果

训练完成后，终端会显示：
```text
============================================================
离线训练执行完毕！
状态: success
已成功合并至生产底表: .../tools/experience_pool/offline_experience.json
更新路口集合: ['1300069']
============================================================
```

1. **总经验底表**：
   位于 `tools/experience_pool/offline_experience.json`。
   - 新路口会自动增量追加，存量老路口原样保留，互不冲突。
   - 每次写入前系统都会自动在同级生成 `.bak` 安全备份文件。

2. **训练质检分析报告**：
   位于 `tools/logs_data/offline_training/<运行时间戳>/`。
